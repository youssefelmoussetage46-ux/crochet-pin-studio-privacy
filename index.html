Privacy Policy

Crochet Pin Studio

Last updated: November 10, 2026

1. About this application

Crochet Pin Studio is a desktop tool for preparing images, titles, descriptions, and review queues for Pinterest content promoting digital crochet patterns. The current desktop version operates locally and does not connect to Pinterest or automatically publish Pins. Pinterest account integration is planned, but not yet available.

2. Information processed

The current application processes product images, product names, descriptions, keywords, Etsy destination URLs, and approval records that the operator supplies. These files are saved locally on the operator's computer.

If a future Pinterest API integration is enabled, the application may, with the account holder's authorization, access account identifiers, board information, Pin information, and authorization tokens needed for requested functions. This policy will be updated to reflect the implemented integration before it is enabled.

3. Purpose and publishing approval

Data is used to create and review draft Pins and export a local publishing plan. The current application does not transmit content to Pinterest. Future publishing features are intended to require explicit approval before submission.

4. Storage and security

The current application stores its working files locally. It does not operate a hosted user database. The operator is responsible for protecting their computer and local files. Any future credential storage will require appropriate security safeguards before deployment.

5. Sharing

The current application does not sell personal data or send application content to a hosted Crochet Pin Studio service. If Pinterest integration is implemented, information necessary to carry out authorized requests will be sent to Pinterest, subject to Pinterest's own privacy practices.

6. Retention and deletion

Local files remain until deleted by the operator. The operator can remove generated images, metadata, and exports from the application folders. Future account disconnection and token deletion procedures will be documented before integration launches.

7. Third parties

For information about Pinterest's data handling, see Pinterest's Privacy Policy.

8. Updates

This policy may change as features are added. The date at the top will be updated when material changes are published.
